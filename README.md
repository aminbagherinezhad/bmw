# Sutton Car Care Centre — Website Redesign

Modern, responsive landing + book-online pages inspired by [suttoncoldfieldmot.co.uk](https://www.suttoncoldfieldmot.co.uk/), with a **blue + gold** brand palette.

## Pages

- `index.html` — Home
- `book-online.html` — Service catalogue & booking
- `login.html` — Sign in
- `register.html` — Create account
- `orders.html` — Track bookings (login required)
- `seller-login.html` — Seller sign in / register
- `seller-dashboard.html` — Seller sales & revenue overview
- `seller-products.html` — Create products, stock & sales

Auth, orders and seller data are front-end demos using `localStorage`.

## Run locally

```bash
npx --yes serve . -l 5173
```

Then open:
- http://localhost:5173/
- http://localhost:5173/book-online.html
- http://localhost:5173/seller-login.html
